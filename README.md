# Cassandra Responde

Oráculo doméstico no estilo **Pedro Responde**, com o clima da série *Cassandra* (Netflix). Em pt-BR.

## Como jogar (para quem mostra aos amigos)

1. Escreva um **pedido** educado: `Cassandra, favor responder`
2. Faça a **pergunta** terminando com `?`
3. Envie — a casa consulta a tela

## O truque (não contar)

No campo Pedido, digite `.` + a resposta secreta + `.`  
Enquanto digita a resposta, o ecrã mostra a frase cortês. Depois escreva a pergunta e envie.
